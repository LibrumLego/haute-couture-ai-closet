# 오트 쿠튀르

**내 옷장 기반 AI 코디·쇼핑 도우미**

모두의 AI 실험실 지원을 위한 팀 프로젝트 저장소입니다.

## 프로젝트 소개

옷을 계속 사기 전에 이미 가진 옷을 다시 발견하고 활용할 수 있도록, 사진으로 옷을 기록하고 보유 의류 안에서 코디를 제안하며 구매 후보와 옷장의 중복을 비교하는 서비스를 구상합니다. AI가 제안한 옷 종류·색상·계절 태그는 사용자가 확인하고 수정한 뒤 저장하는 흐름을 목표로 합니다.

## 현재 단계

개인 사용과 포트폴리오 공개를 위한 모바일 우선 프로토타입이 있습니다. 정식 출시, 외부 사용자 대상 서비스 운영, 사용자 인터뷰와 사용성 테스트는 아직 진행하지 않았습니다. 이 저장소는 오트 쿠튀르 팀의 프로젝트별 구현과 검증 과정을 정리하기 위해 만들었습니다.

현재 프로토타입의 소스 코드는 [ai-wardrobe-portfolio](https://github.com/LibrumLego/ai-wardrobe-portfolio)에서 확인할 수 있습니다.

## 주요 기능 구상

- 사진과 카테고리·색상·계절·메모를 이용한 의류 기록
- 등록된 보유 의류 안에서 코디 제안
- AI 태그 제안을 사용자가 검토·수정한 뒤 저장
- 쇼핑 후보와 현재 옷장을 비교해 중복 확인
- 사용자 인터뷰와 사용성 테스트를 통한 개선

## 팀 역할

- **국지민** — 문제 정의, 서비스 기획, AI 기능 구현
- **박재현** — 사용자 조사, 서비스 디자인, 사용성 테스트와 피드백 정리

## 기술 스택

Vanilla JavaScript, HTML, CSS, IndexedDB, Vercel Serverless Functions, OpenAI Responses API
